Python 教学平台 · 本地版 使用说明
================================================

一、这台电脑要装什么
------------------------------------------------
必须装 Python（代码运行、点名、绘图全靠它）：

  1) 到 python.org 下载 3.11 ~ 3.13（推荐 3.13，64 位）
     安装时务必勾选【Add python.exe to PATH】
  2) 装完打开命令提示符（Win+R 输入 cmd），执行：

     pip install matplotlib numpy pandas seaborn networkx

装完可以验证一下：

     python --version
     python -c "import matplotlib, numpy, pandas; print('ok')"

能打印 ok 就齐了。如果只打印 ok 但绘图仍报错，多半是 pip 装到了
另一个 Python 上 —— 用 where python 看一下有几个。

.NET 运行时不用装：本目录是「自包含」版本，运行时已经打包在里面。


二、怎么启动 / 停止
------------------------------------------------
  启动：双击【启动.bat】
        会自动选一个空闲端口（5188~5199），等服务起来后打开浏览器。
        不需要登录，直接进工作台。

  停止：双击【停止.bat】
        直接关浏览器不会停止服务，用这个脚本关，或重启电脑。

如果双击后浏览器打开是空白 / 打不开，等 3~5 秒刷新一次；
杀毒软件首次运行时可能拦一下，选「允许」。


三、侧栏的四个入口
------------------------------------------------
「Python 教学」分组下：

  在线演示  —— 金山文档 iframe 播放课件（需要联网）
  课件文件  —— 管理课件链接、挂载到代码旁
  代码文件  —— 代码库，增删改查 / 重命名 / 移动 / 上传 .py
  实用工具  —— 课堂点名、考勤统计、名单管理

原来模块里的那几个页内按钮已经隐藏了，功能一个不少，都在这四项里。

本机是「纯教学机」：只保留 Python 教学模块，其他模块（工作台、日程、
备忘、记账、情侣……）一律不可访问 —— 打开首页会直接进教学页，手输
别的地址也会被拉回来。这些模块的代码还在程序里（线上版仍在用），
只是这台机器上不开放。


四、课件怎么准备
------------------------------------------------
平台本身不存 PPT 文件，只存「金山文档分享链接」。步骤：

  1) 把 pptx 上传到金山文档（kdocs.cn）
  2) 点「分享」复制链接（形如 https://www.kdocs.cn/l/xxxxxxxx）
  3) 在【课件文件】里新增，填入标题和链接
  4) 在【在线演示】里选中它播放

断网时代码、点名、绘图照常用，只有课件区打不开。


五、数据在哪、怎么备份
------------------------------------------------
全部数据在程序目录的 data 文件夹里（checkin.db + keys）。

  手动备份：双击【备份数据.bat】，生成 backup\pylab-data-日期.zip
  换电脑：  先【停止.bat】，把整个文件夹拷过去即可；或者只把
            backup 里的 zip 解压回 data 目录。
  清空重来：停止后删掉 data 文件夹，下次启动会自动重建（名单和
            代码都会没了，删之前先备份）。


六、常见问题
------------------------------------------------
Q: 浏览器打开提示「无法访问此网站」？
A: 服务还没起来（慢机器要 10 秒以上），或者被 360/火绒拦了。
   看任务栏有没有一个最小化的 PyLabServer 窗口，里面有报错信息。

Q: 页面上「Python 就绪」变成红色 / 提示未找到 Python？
A: Python 没装好或没进 PATH。装好后重启一次「启动.bat」。
   如果装了多个 Python，可以在程序目录新建 appsettings.Local.json：

   {
     "PyLab": {
       "PythonPath": "C:\\Users\\你的用户名\\AppData\\Local\\Programs\\Python\\Python313\\python.exe"
     }
   }

   注意路径里的反斜杠要写两条。

Q: 想换端口？
A: 不用换，程序会自己找 5188~5199 里空闲的那个。

Q: 想让局域网里其他电脑也能访问？
A: 默认只监听 127.0.0.1（安全）。需要多人用时再说，别直接把端口
   暴露到公网 —— 单机模式是免登录的，公网上等于谁都能进。


七、目录里都有什么
------------------------------------------------
  CheckinApp.exe      主程序（自带 .NET 运行时）
  appsettings.json    站点配置
  tools\pylab\        Python 沙箱引擎与假 tkinter
  wwwroot\            前端资源（主题、样式、脚本）
  data\               运行后生成：数据库与密钥（要备份的就是它）
  backup\             备份脚本生成的 zip
  启动.bat / 停止.bat / 备份数据.bat / 使用说明.txt
